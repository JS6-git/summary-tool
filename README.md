# 文章要約ツール（summary_tool）

長い文章を、**3〜5行の箇条書き**に要約するコマンドラインツールです。
ニュース記事や調べもので見つけた長文を、さっと把握するために作りました。
要約には Claude API（Anthropic）を使っています。

## 動作例

`samples/sample_news.txt`（中小企業の生成AI活用に関するニュース風の文章）を要約した結果：

```
> python summary.py samples/sample_news.txt
- 従業員100人未満の企業で生成AIを日常業務に使う割合は、前年の18%から31%に上昇した。
- 主な用途はメールや資料の下書き、議事録作成、社内マニュアル検索で、導入企業の多くが作業時間の短縮を実感している。
- 一方で人材不足や情報漏えいへの不安などの声も多く、導入を見送った企業の半数近くが相談相手がいないことを理由に挙げた。
- 外部の専門家に小さな業務から自動化を任せる企業も出ており、専門家は効果が見えやすい作業から試して範囲を広げる進め方を勧めている。
```

## できること

- **貼り付けた文章を要約**：実行後に文章を貼り付け、最後に「おわり」と入力
- **テキストファイルを要約**：`python summary.py ファイル名` で指定（UTF-8 / Shift_JIS 対応）
- **3〜5行に収める**：行数が範囲外だった場合は、自動で1回だけ作り直す
- **エラーは日本語で表示**：APIキー未登録・キー無効・通信エラー・利用上限・混雑・ファイルが見つからない など

## 必要なもの

- Python 3
- Anthropic の APIキー（[Claude Console](https://console.anthropic.com/) で発行）

## セットアップ

1. ライブラリをインストールします。

   ```
   pip install anthropic
   ```

2. APIキーを環境変数 `ANTHROPIC_API_KEY` に登録します（Windows の例）。
   登録後は PowerShell を開き直してください。

   ```
   setx ANTHROPIC_API_KEY "ここに自分のAPIキー"
   ```

   ※APIキーはコードやファイルに書かず、環境変数で管理しています。

## 使い方

### 文章を貼り付けて要約する

```
python summary.py
```

1. 「要約したい文章を貼り付けてください」と表示されたら、文章を貼り付けます（右クリック または Ctrl+V）。
2. 貼り付けた文章の最後で **Enter** を押して、新しい行に移ります。
3. 新しい行に「**おわり**」と入力して Enter を押すと、要約が表示されます。

```
要約したい文章を貼り付けてください。最後に「おわり」とだけ書いた行を入力してEnter。
来週から社内の会議室予約のルールが変わります。……   ← 貼り付けた文章
当日キャンセルする場合は……                          ← 貼り付けた文章の最後（ここでEnter）
おわり                                               ← 新しい行に入力してEnter
- 来週から会議室の予約方法が……                       ← 要約が表示される
```

※「…お願いします。おわり」のように文章と同じ行に書くと、終わりの合図になりません。必ず「おわり」だけの行にしてください。

### テキストファイルを要約する

```
python summary.py samples/sample_news.txt
```

## しくみ（ざっくり）

1. 文章を受け取る（貼り付け or ファイル）
2. 「3〜5行・各行は『- 』で始める・本文にないことは足さない」と指示して Claude に送る
3. 返ってきた答えから「- 」で始まる行だけを取り出して表示する
4. 行数が3〜5行でなければ、もう一度だけ直してもらう

## ファイル構成

```
summary_tool/
├── summary.py          … 本体
├── samples/
│   └── sample_news.txt … 動作確認用のサンプル文章

```
